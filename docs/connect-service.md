# Подключить сервис к pulse — задание для агента

Подключи сервис из текущего репозитория к pulse по стандарту манифеста сервиса.

1. Скачай стандарт curl'ом во временный файл и прочитай целиком — не через краткий пересказ
   веб-инструмента: `https://raw.githubusercontent.com/rendau/pulse/master/docs/service-manifest.md`.
2. Работай по его разделу «Для агента, который реализует стандарт в сервисе»: изучи код →
   спроси у меня факты из прода и недостающее → покажи черновик манифеста и план изменений →
   **жди моего подтверждения** → реализуй → проверь и отчитайся.
3. Go — модуль pulsekit: `git clone --depth 1 https://github.com/rendau/pulse` во временный
   каталог, скопируй все файлы `internal/infra/pulsekit`, кроме `pulse_test.go`, затем
   `go mod tidy`. Другой стек — ручки по стандарту средствами своего фреймворка.

Нельзя: читать секреты (`.env`, значения в кластере, `values/` helm-репозиториев); менять CI,
Dockerfile и чарт без моего согласия; коммитить без моего согласия.
